# XML-only example

`VisibleClothing_XmlExample` is a complete add-on mod with no models of its own. It adds one new item, the
**Scavenger's Balaclava** (`clothingHeadXmlExampleBalaclava`), which reuses Visible Clothing's ThermaCore balaclava
model through `#@modfolder(VisibleClothing):Resources/...`.

Install: copy the `VisibleClothing_XmlExample` folder into `7 Days To Die/Mods/` next to `VisibleClothing`. The item
is in the creative menu. See [docs/MAKING_CLOTHING.md](../../docs/MAKING_CLOTHING.md#a-xml-only-reuse-a-model).
